# ELASTICO AI 2.0 — MASTER INTELLIGENCE DIRECTIVE

## Constitutional Rule

Every AI capability must follow:

SOURCE → POSTGRESQL → EMBEDDINGS → RETRIEVAL → REASONING → API → UI

Never allow:

API → UI.

Never allow:

LLM → UI without retrieval.

Never allow:

Fabricated football knowledge.

## AI Stack

1. PostgreSQL is the permanent knowledge source.

2. pgvector stores embeddings.

3. NVIDIA Nemotron generates embeddings.

4. NVIDIA Reranker ranks retrieved context.

5. Groq/Gemini/Cerebras/OpenRouter generate responses.

6. AI Gateway chooses provider.

7. Every response includes provenance.

8. Every prediction stores outcome for learning.

9. Every conversation stores memory.

10. Every insight stores evidence.

## Completion Definition

ELASTICO AI is complete only when:

* Every football fact is retrievable from PostgreSQL.

* Every AI answer is grounded in retrieved football context.

* Every prediction explains why.

* Every answer shows provenance.

* Every provider is health-monitored.

* Every conversation contributes to memory.

* Every prediction contributes to learning.
